# Titanic Survival Analysis

Exploratory data analysis of Titanic passenger data, investigating which
factors (gender, class, age, family size, fare) were associated with survival.

## Dataset
Source: [Titanic - Machine Learning from Disaster, Kaggle](link)
891 passengers, with survival outcome and demographic/ticket information.

## What I did
- Explored missing data: Age (~20% missing, filled with median), Cabin
  (~77% missing, dropped), Embarked (2 missing, rows dropped)
- Created new features: AgeGroup, FamilySize
- Analyzed survival rate by sex, passenger class, age group, family size, and fare
